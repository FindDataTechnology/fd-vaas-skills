# 图文平台内容规格坑(跨平台)

写进 `.env` 一次,后面每篇文章都对齐。各平台编辑器入口 + 登录 + 发文 heredoc 见 `references/<platform>.md`。

## 内容形态对照

| 平台 | 形态 | 纯文字? | 标题字数 | 正文 | 标签 | 封面 |
|---|---|---|---|---|---|---|
| 知乎 | 专栏长文 | ✅ 可 | ~100 | ~50000 | 话题 ≤5 | 可选 16:9 |
| 公众号 | 图文 | ✅ 可 | 64 | 20000 | 无(用合集) | **必填** 900×500 |
| 小红书 | 图文笔记 | ❌ 必须带图 | **20** | 1000 | 话题 ≤10 | **必填** ≥1 张 3:4 |
| 雪球 | 长文 | ✅ 可 | ~50 | 无硬限 | `$股票` + 话题 | 可选 |
| 东方财富号 | 文章 | ✅ 可 | ~30 | 无硬限 | 标签 | 可选 |
| 同花顺财经号 | 文章 | ✅ 可 | ~30 | 无硬限 | 标签 | 可选 |

publish.mjs 已按这张表自动截标题/正文/标签,但**内容质量你自己把关**——别把知乎长文原样塞小红书(超 1000 字、超 20 字标题全废)。

## Markdown → 各平台正文适配

文档源是 `article.md`(Markdown)。各平台编辑器吃法不同:

- **知乎**:专栏编辑器**支持粘贴 Markdown 自动渲染**。直接把 `DOC_BODY` 粘进正文 contenteditable 即可,标题/列表/代码块会渲染。
- **公众号**:富文本 ueditor,**不支持 markdown 源码**。要么粘贴前手动渲染成富文本(在浏览器里),要么粘 markdown 源码它会当纯文本。**推荐**:正文用 `typeText` 粘纯文本分段 + 手动加粗;或让用户在公众号编辑器里用「md2html」类工具贴。这是公众号最大的坑。
- **小红书**:纯文本笔记体,markdown 符号(`#` `*` `` ` ``)会原样显示很丑。publish.mjs 写 `.adapted/xiaohongshu/body.md` 前**应**剥掉 markdown 符号(可手动,或加个 strip 步骤)。话题 `#标签` 放末尾。
- **雪球/东财/同花顺**:富文本,粘 markdown 源码会当纯文本。同公众号,推荐纯文本分段或用户手动渲染。

> 实操:对公众号/雪球/东财/同花顺,heredoc 里**优先 `typeText` 纯文本正文**(strip 掉 markdown 符号),别直接灌 markdown 源码。知乎可灌 markdown。

## 封面图

- 用 **fd-cover-image**(Remotion)生成,**别用 AI 生图**(文字会乱码)。
- 公众号封面必填,建议 900×500(2.35:1 也行);小红书竖图 3:4(1080×1440);其余横图 16:9。
- 小红书图文**至少 1 张图**,纯文字发不出。

## 摘要 / 简介

- **公众号摘要必填**,不填发布按钮灰。publish.mjs 没给 `summary` 时从正文前 120 字生成,写进 `.adapted/weixin/summary.txt`(heredoc 用 `DOC_SUMMARY`)。
- 其余平台摘要可选。

## 原创声明

- 知乎/公众号有「原创声明」开关,声明后才有版权保护、推荐权重高。**默认不勾**(声明需账号有原创权限,乱勾会被罚);用户明确要再勾。
- 雪球/东财/同花顺一般无单独原创开关。

## 登录态

- 全部走 **ego-browser 继承的 Chrome 登录态**,**无 cookie 文件、无 account**。
- 每个平台在**自己的 Chrome** 里登进对应创作者后台一次,后续 ego-browser 复用。
- 没登录 -> heredoc 检测到登录页 -> `handOffTaskSpace` 交还用户扫码 -> `takeOverTaskSpace` 收回。
- **首次登录建议 `DOC_HEADLESS=false`**(有头),QR 才好扫;登进后可改回 `true`。

## 风控 / 串行

- **不要并发跑同一账号的多个平台发布**。浏览器上下文共享会打架。多平台**串行**,一个发完再发下一个。
- 短时间大量发文 / 切账号会被风控验证码。别一次跑太多篇。
- 公众号群发有频次限制(订阅号每天 1 次),**默认存草稿不群发**,让用户手动群发。

## 定时发布

- 知乎/公众号/雪球支持定时;小红书图文支持定时;东财/同花顺看后台。
- heredoc 里「定时」需要手动点「定时发布」+ 选时间,选择器各平台不同,首次 probe 确认。`--schedule` 传了就尝试,没传就立即发(公众号默认存草稿)。

## 各平台资质门槛

- **东方财富号 / 同花顺财经号**:需要先申请财经号/媒体号资质,没开通后台没有发文入口。先去 oa.eastmoney.com / media.10jqka.com.cn 开通。
- 知乎/公众号/小红书/雪球:普通账号即可发(公众号需订阅号/服务号)。
