# VAAS Brainstorm Skill

> 口播 + 图文双模式的内容策划辅助工具。给定赛道 / 主题 / 受众,产出结构化选题方向,以及可直接用的口播大纲或图文草稿。

## 两种模式

按用户需求切换;**没明说口播还是图文就先问一句**,别默认。

| 模式 | 产出 | 典型场景 |
|------|------|---------|
| **口播** | 选题矩阵 + 脚本框架 + 差异化角度 + 完整口播大纲 | 短视频 / 口播脚本(交给 fd-vaas-video-creator 出片) |
| **图文** | 选题矩阵 + 标题组 + 正文草稿(Markdown 版 + 纯文本简洁版) + 标签 | 公众号 / 知乎 / 小红书 / 雪球 / 东财 / 同花顺等图文平台(交给 fd-vaas-publish-docs 分发) |

## 红线与合规限制(重要,所有产出必须过)

### 口播视频红线

口播稿(口播文本 + 字幕 + 画面文案)严禁踩以下红线,踩了平台会限流甚至判违规:

- **不得出现其他平台名** -- 禁止口播 / 字幕 / 画面出现「抖音」「B 站」「小红书」「知乎」「公众号」「微信」「微博」「快手」「视频号」等任何其他平台名称。需要提及时用「某个平台」「某 App」「某社区」等代称,或直接删掉。
- **不得引流到站外** -- 禁止出现外链、二维码,以及"私信我""加微信""加群""主页有链接""搜索 XXX""点左下角""评论区留邮箱"等任何把用户导离当前平台的行为。**CTA 只能用平台内动作**:点赞 / 关注 / 收藏 / 评论 / 转发 / 「主页还有更多」。
- **不得出现联系方式** -- 手机号 / 微信号 / QQ 号 / 邮箱 / 个人网址一律不进稿。
- **敏感品类克制** -- 金融、医疗、投资建议类表述需克制,不构成具体投资 / 用药建议。

### 图文合规

- 同样遵守上述平台名 / 站外引流 / 联系方式限制(各平台规则不同,默认从严)。
- 不同平台字数 / 标签数 / 摘要 / 封面要求不同,正文需按目标平台适配(详见 fd-vaas-publish-docs)。

## 用法

### 前置工作流(硬性,必须先做)

接到策划需求后,**不要上来就空想选题**,按以下顺序收集信息:

1. **读项目内公开资料** -- 先检查仓库里有没有现成的品牌素材 / 产品介绍 / Slogan / 愿景使命 / 历史脚本 / 过往成片,**复用已有定位和话术**,不要凭空发明。
   - `downloads/fd-videos/<slug>/script.txt` -- 历史口播稿,复用品牌调性
   - `downloads/fd-docs/<slug>/article.md` -- 历史图文,复用行文风格
   - `downloads/common/` -- 通用素材(片尾、封面、图标等)
   - 项目 README / docs / 官网文案 -- 产品定位、功能描述、Slogan
   - `AGENTS.md` -- 项目整体介绍和产品矩阵

2. **读共同资料库** -- 检查 `VAAS/_assets/`、`VAAS/downloads/common/` 以及任何约定俗成的「品牌公共素材目录」,确认:
   - 品牌色 / Logo / 视觉规范
   - 标准 Slogan 和使命愿景表述
   - 产品名称的标准写法(大小写、缩写、英文原名)
   - 统一的 CTA 话术(平台内动作,见红线)

3. **确认模式与目标平台** -- 口播还是图文?给抖音竖屏还是 B 站长视频?图文发公众号还是知乎 / 小红书?据此调整话术深度、时长、字数。

4. **确认核心信息点** -- 这条内容最重要的 1~3 个信息是什么?其余内容可以砍掉。

收集齐以上信息后,再开始选题 brainstorm 和脚本 / 草稿撰写。**输出必须与品牌已有资料保持一致**,不得出现产品名写错、Slogan 对不上、定位冲突等低级错误;**且必须通过上面的红线自检**。

### /fd-vaas-brainstorm

调用 skill 传入赛道 / 主题,可显式指定模式:

```
/fd-vaas-brainstorm 口播 职场成长
/fd-vaas-brainstorm 图文 AI工具 程序员
/fd-vaas-brainstorm 护肤 敏感肌 25-35岁女性   (没指定模式就先问)
```

## 输出结构

### 口播模式

#### 1. 选题矩阵

按 5 个维度各出 3-5 个选题:

| 维度 | 说明 | 示例 |
|------|------|------|
| **热点型** | 借势热点、节日、趋势 | "最近爆火的 DeepSeek,普通人怎么用?" |
| **痛点型** | 用户真实困扰、焦虑 | "为什么你学了很多课还是没进步?" |
| **争议型** | 反常识、颠覆认知、站队 | "我劝你别做自由职业" |
| **干货型** | 方法论、技巧、教程 | "3 个让你表达力翻倍的训练方法" |
| **人设型** | 个人故事、经历、感悟 | "从月薪 3k 到 3w,我做对了什么" |

#### 2. 脚本框架(推荐 + 备选)

为每个选题推荐 1-2 个脚本结构:

| 框架 | 适合场景 | 结构 |
|------|---------|------|
| **黄金三秒+痛点+方案** | 通用爆款 | 钩子(3s) -> 共情痛点 -> 解决方案 -> 引导 |
| **SCQA** | 知识/观点 | 情景 -> 冲突 -> 问题 -> 答案 |
| **PREP** | 说服型 | 观点 -> 理由 -> 案例 -> 重申观点 |
| **故事钩子** | 人设/叙述 | 悬念开头 -> 情节展开 -> 转折 -> 感悟 |
| **清单体** | 干货/技巧 | "XX 个方法" -> 逐条展开 -> 总结 |

#### 3. 差异化角度

针对每个选题给出 2-3 个"爆款切入点"--让选题不撞车的角度。

#### 4. 完整大纲(可选)

对选定的 1 个选题展开为 300-500 字的口播脚本大纲,含:

- 开场钩子(具体话术)
- 正文结构(分点 / 分段)
- 结尾引导(**只用平台内动作**:点赞 / 关注 / 评论;不得出现其他平台名 / 站外引流)

### 图文模式

#### 1. 选题矩阵

复用口播的 5 维度选题矩阵,但适配图文(更适合长文 / 深度展开 / 可检索)。

#### 2. 标题组

为每个选题出 3-5 个标题候选,覆盖不同风格:

- 提问式:"为什么 ……?"
- 数字式:"N 个 ……"
- 悬念式:"我 …… 之后才发现"
- 价值式:"…… 完整指南 / 从 0 到 1"

#### 3. 正文草稿(双版本,内容一致,排版不同)

对选定 1 个选题产出 800-1500 字正文,**必须同时给两个版本**:

- **Markdown 版** -- 完整 markdown 结构:`#` 标题 / `##` 小标题 / `-` 列表 / `**加粗**` / `> ` 引用 / 代码块。适合支持 markdown 的编辑器(知乎、公众号、博客等)。
- **纯文本简洁版** -- 去掉所有 markdown 语法符号,用纯文字 + 空行 + 编号(一、二、 或 1. 2.)组织结构,**不得出现 `#` `*` `>` `-` 等 markdown 符号**。适合不支持 markdown 的编辑器(部分平台粘贴 markdown 会原样显示这些符号)。

> 两版正文内容必须一致,只是排版语法不同。先写 Markdown 版,再由它派生纯文本版。

#### 4. 标签组

5-8 个标签,适配主流图文平台(知乎话题 / 小红书话题 / 雪球标签等)。

#### 5. (可选)封面文案 / 摘要

100 字以内摘要 + 封面主文案。

## 口播类型速查

| 类型 | 核心 | 语速 | 时长建议 |
|------|------|------|---------|
| 知识分享型 | 信息密度 + 易懂 | 中速 | 60-120s |
| 观点输出型 | 立场鲜明 + 逻辑强 | 中快 | 45-90s |
| 故事叙述型 | 情绪起伏 + 真实感 | 慢-中 | 90-180s |
| 产品种草型 | 场景 + 利益点 | 中快 | 30-60s |
| 情绪共鸣型 | 共情 + 金句 | 慢-中 | 30-60s |

## 图文平台速查(字数 / 标签参考)

| 平台 | 正文字数 | 标签 | 建议版本 |
|------|---------|------|---------|
| 公众号 | 不限 | - | Markdown 版 |
| 知乎 | 不限 | 话题 | Markdown 版 |
| 小红书 | 1000 字内最佳 | # 话题 | 纯文本版(偏短偏轻) |
| 雪球 | 不限 | # 标签 | Markdown 版 |
| 东财 / 同花顺 | 偏短 | - | 纯文本版 |
| 微博 | 140 / 长文 | # 话题 | 纯文本版 |

> 字数 / 标签数最终以 fd-vaas-publish-docs 的 `.env` 平台配置为准。

## 选题 / 合规 Checklist

产出后逐条自检:

- [ ] 前 3 秒 / 标题能让受众停下来?(钩子强度)
- [ ] 内容有「信息增量」?(不是常识复读)
- [ ] 受众看完会想转发 / 评论?(互动钩子)
- [ ] 和账号定位一致?(人设一致性)
- [ ] 同赛道有类似内容吗?(差异化 ≥ 60%)
- [ ] **口播稿无其他平台名?无站外引流 / 联系方式?**(红线)
- [ ] **图文已出 Markdown 版 + 纯文本简洁版双版本?**(红线)
- [ ] 产品名 / Slogan / 定位与品牌资料一致?

## 示例

```
/fd-vaas-brainstorm 口播 职场沟通 内向者
```

输出:选题矩阵 + 脚本框架 + 差异化角度 + 最强 1 个选题的完整口播大纲(CTA 仅平台内动作)。

```
/fd-vaas-brainstorm 图文 AI工具 程序员
```

输出:选题矩阵 + 标题组 + 1 篇正文(Markdown 版 + 纯文本简洁版)+ 标签 + 摘要。
