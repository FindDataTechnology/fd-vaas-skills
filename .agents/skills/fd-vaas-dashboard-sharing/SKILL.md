# 分享看板

选择分享方式将 VAAS 看板分享给他人。

## 用法

```bash
/share-dashboard     # 弹出分享方式选择
```

## 分享方式

| 方式 | 场景 | 延迟 |
|------|------|------|
| WiFi 局域网 | 同一 WiFi 下的设备 | 最低 |
| Bore Tunnel | 公网 / 跨网 | 中 |
| Cloudflare Tunnel | 公网 / 跨网 | 中高 |
