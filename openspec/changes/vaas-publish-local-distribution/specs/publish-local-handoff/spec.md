# Publish Local Handoff Spec Delta

## Purpose

云端生成产物到本地发布之间的交接契约：租户从托管实例取回自己名下的产物，在本机完成平台适配与人工确认后经浏览器发布，发布回执回流统一物料库。登录态全程只存在于用户本机。

## ADDED Requirements

### Requirement: 凭租户身份拉取云端产物

本地发布技能 SHALL 能凭租户在谦面的调用键（或租户直接提供的签名下载 URL）从其归属的托管实例拉取产物：按 owner 过滤列出与读取资产、取回文件内容到本地 `downloads/` 标准目录。无调用键且无签名 URL 时 MUST 给出引导而非报错堆栈。平台侧 MUST NOT 提供任何绕过 owner 隔离的拉取通道。

#### Scenario: 调用键拉取

- **WHEN** 租户在本机以自己的调用键请求列出并下载名下产物
- **THEN** 只能看到与取回 owner 等于自己的资产
- **AND** 文件落盘到与类型对应的 downloads/ 目录并可直接进入发布流程

#### Scenario: 签名 URL 直取

- **WHEN** 租户把托管生成响应里的签名下载 URL 粘给本地技能
- **THEN** 链接过期或签名不符时得到明确的过期提示并可从托管实例重新取 URL
- **AND** 下载内容与生成产物一致

### Requirement: 登录态只存本机且不进云

发布所需的平台登录态 SHALL 只保存在用户本机的专用 profile（扫码/窗口登录由本机 fd-vaas-login 触发）；本地技能 MUST NOT 提供任何把 cookies、登录态或平台凭据上传到平台侧的工具或配置项。平台侧 MUST NOT 请求、存储或中转任何平台登录态。

#### Scenario: 登录在本机完成

- **WHEN** 租户在本机打开登录管理页扫码
- **THEN** cookies 只写入本机专用 profile 目录
- **AND** 平台侧审计与存储中不出现该登录态的任何痕迹

#### Scenario: 无上传通道

- **WHEN** 检查本地发布技能的工具面与配置面
- **THEN** 不存在任何接收或转发平台凭据的入口
- **AND** 打包分发物（pack）中同样不包含此类入口

### Requirement: 人工确认后发布并回执

本机发布 SHALL 维持既有硬性流程：平台适配（dry-run 预览）→ 用户逐平台确认 → 浏览器发布；发布结果 SHALL 回写统一物料库（distribution 记录），使云端素材库能看到该产物的发布状态。发布失败的平台 MUST 不影响其他平台。

#### Scenario: 确认后才真发

- **WHEN** 本地技能完成平台适配
- **THEN** 先向用户展示各平台将要发布的标题/正文/标签/封面
- **AND** 未获用户明确确认前不执行任何真实上传

#### Scenario: 回执回流

- **WHEN** 某平台发布成功
- **THEN** distribution 记录更新（平台、URL、时间）
- **AND** 同一产物在托管实例的资产详情中可见其发布状态
