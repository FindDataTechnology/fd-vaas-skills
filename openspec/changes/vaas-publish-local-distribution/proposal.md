# VAAS 发布面本地分装（云端生成 · 边缘发布）

## Why

发布（publish_*）是租户的核心需求，但账号登录态的安全边界决定了它不能上云：把多用户的平台 cookies 收进平台服务器 = 平台成为账号保管员，泄露面与责任都不可接受（ADR-0004 的既定否决）。而租户的实际使用形态——本地下载 MCP、本地跑——恰好是发布的安全形态：登录态永远不离开用户自己的电脑，平台零保管。本 change 把这条「本机发布」路径从作者的个人用法**产品化**为所有租户的标准用法，并与已上线的托管生成面拼成完整闭环：云端生成 → 签名 URL 下发 → 本地适配 → 用户确认 → 浏览器发布。

## What Changes

- **内容交接通道**：本地发布技能新增「从托管实例拉取产物」入口——凭租户调用键经谦面网关调 `assets_get` 取签名下载 URL（或直接粘贴 URL），产物落 `downloads/fd-docs|videos/` 后走既有发布流程。托管侧零改动（签名 URL 已上线）。
- **谦面分装 pack**：把 fd-vaas-login + fd-vaas-publish-docs + fd-vaas-publish-videos + 依赖清单打包为谦面市场可安装的本地发布 pack（facet-pack-builder 流程），含「云端生成实例地址」配置项（默认指向 `https://mcp.finddatatech.cloud/vaas-wanxing`，租户可覆写）。
- **安全说明页**：随 pack 附一页用户安全说明——登录态存哪、谁碰得到、如何注销、账号风险边界与平台侧零保管声明。
- **ADR-0004 叙事升级**：把「发布面留本机」从排除项升格为产品形态「云端生成、边缘发布」（决策不变，规格化理由与翻案条件）。

## Capabilities

### New Capabilities

- `publish-local-handoff`: 云端产物到本地发布的交接契约——拉取、落盘、确认发布、回执记录的端到端行为。

### Modified Capabilities

（无——发布技能本身的行为契约不变；pack 分装是分发形态，安全说明是文档。）
