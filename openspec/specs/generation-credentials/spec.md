# generation-credentials Specification

## Purpose

VAAS 生成凭证解析链：线池/服务默认两级 vault 解析、按次环境注入与工具参数防夹带的安全契约。为托管多租户生成调用挑选供应商凭证：OpenBAO 运行时拉取带 TTL 缓存，轮换免重新部署，凭证永不进入工具参数或日志。

## Requirements

### Requirement: 凭证存放与 bootstrap

托管模式下，模型凭证 SHALL 存放于平台密钥库（OpenBAO）并按路径分池：每条产品线一个线池路径，另有一个服务默认路径。服务进程环境变量 SHALL 只包含密钥库地址与受限工作令牌（bootstrap），MUST NOT 包含任何模型供应商凭证明文。本地（非托管）模式 SHALL 保持从 `.env` 读取凭证的现有行为。

凭证记录 SHALL 携带 `provider` 字段声明其后端档位；受支持的档位集合为 `volcengine`
（火山方舟直连）与 `ciyuan`（萬星·词元车道）。缺失时按 `volcengine` 处理以兼容既有记录。

#### Scenario: 托管进程环境无凭证明文

- **WHEN** 托管模式的服务进程启动
- **THEN** 其环境变量不含任何模型供应商凭证
- **AND** 首次生成调用能经密钥库取得凭证并成功

#### Scenario: 本地模式不依赖密钥库

- **WHEN** 本地 stdio 模式启动且密钥库不可达
- **THEN** 生成调用仍按 `.env` 配置成功
- **AND** 行为与本 change 之前一致

#### Scenario: 凭证记录声明后端档位

- **WHEN** 管理员在密钥库写入一条生成凭证
- **THEN** 该记录可声明 `provider` 为 `volcengine` 或 `ciyuan`
- **AND** 生成调用按该声明选择后端，无需改代码

#### Scenario: 未声明档位的既有记录保持原行为

- **WHEN** 一条未带 `provider` 字段的既有凭证记录被解析
- **THEN** 该记录按 `volcengine` 档处理
- **AND** 生成行为与本 change 之前一致

### Requirement: 解析优先序

每次生成调用，系统 SHALL 按「请求级凭证引用 → 租户自带凭证 → 线池凭证 → 服务默认」的固定优先序解析凭证；一期实际生效的解析为「线池凭证 → 服务默认」，请求引用与自带凭证两级为二期预留位且 MUST NOT 影响一期行为。解析结果 SHALL 记入用量（凭证来源字段）。

用量记录的凭证来源 SHALL 能区分后端档位：词元车道调用标注的来源 MUST 能与火山方舟
调用区分，以便按后端对账。

#### Scenario: 线池优先于默认

- **WHEN** 萬星线实例处理一次图片生成且线池凭证存在
- **THEN** 本次调用使用线池凭证
- **AND** 用量记录的凭证来源为线池

#### Scenario: 线池缺失回落默认

- **WHEN** 线池路径尚未配置凭证
- **THEN** 本次调用回落到服务默认凭证并成功
- **AND** 用量记录的凭证来源为服务默认

#### Scenario: 用量可按后端档位区分

- **WHEN** 同一实例分别经火山方舟与词元车道完成生成
- **THEN** 两条用量记录可据其后端档位区分归属
- **AND** 凭证来源字段如实反映实际使用的档位

### Requirement: 按次注入与缓存

解析出的凭证 SHALL 以环境变量注入当次生成的子进程，MUST NOT 写入持久文件、数据库或日志。凭证 SHALL 带 TTL 缓存（默认 300 秒）以减少密钥库访问；密钥库中轮换凭证后，新调用 SHALL 在缓存过期后取到新凭证，MUST 无需重新部署。

注入的环境变量集合 SHALL 随 `provider` 档位而变：`volcengine` 档注入方舟环境变量名，`ciyuan` 档注入词元车道所需的地址、密钥与模型环境变量。词元分组约束（一把密钥只绑一个分组）SHALL 通过按 kind 分路解析满足，MUST NOT 要求单一凭证覆盖全部生成类型。

#### Scenario: 子进程环境隔离

- **WHEN** 一次图片生成执行
- **THEN** 只有该次子进程环境包含解析出的凭证
- **AND** 工具响应、日志与数据库记录中不出现凭证明文

#### Scenario: 免部署轮换

- **WHEN** 管理员在密钥库中更换线池凭证
- **THEN** 至多一个缓存周期后新调用使用新凭证
- **AND** 服务进程未重启

#### Scenario: ciyuan 档注入词元环境变量

- **WHEN** 解析出的凭证 provider 为 `ciyuan`
- **THEN** 子进程环境收到词元基址、该 kind 的 API key 与模型名
- **AND** 环境不含方舟环境变量名

#### Scenario: 语音与图像可使用不同分组的凭证

- **WHEN** 线池为 tts 与 image 分别配置了不同分组的词元 key
- **THEN** 两类生成各自注入所属 kind 的 key 并可分别成功
- **AND** 任一路凭证缺失只影响该路生成

### Requirement: 凭证不过工具参数

任何工具的入参 SHALL NOT 接受模型凭证明文；带凭证明文的调用 MUST 被拒绝并提示使用凭证引用。请求级凭证引用（二期）只允许传凭证名称，MUST NOT 传凭证值。

词元密钥形态（`sk-` 前缀长串）SHALL 被纳入凭据形态识别，与方舟密钥形态同等拦截。

#### Scenario: 拒绝参数夹带

- **WHEN** 客户端在生成工具参数中传入 API key 明文
- **THEN** 调用被拒绝并返回参数违规提示
- **AND** 该明文不出现在任何日志或审计记录中

#### Scenario: 词元形态密钥同样被拦截

- **WHEN** 工具参数中出现词元形态的 API key
- **THEN** 该调用被拒绝，判据与方舟密钥一致
