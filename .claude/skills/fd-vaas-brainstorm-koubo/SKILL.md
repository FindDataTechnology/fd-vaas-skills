# 口播 Brainstorm Skill

> 口播短视频的内容策划辅助工具。给定一个赛道或主题，产出结构化的选题方向和脚本大纲。

## 用法

### /koubo-brainstorm

直接在当前对话中调用 skill，传入你的赛道/领域/主题：

```
/koubo-brainstorm 职场成长
/koubo-brainstorm 护肤 敏感肌 25-35岁女性
/koubo-brainstorm AI工具 程序员
```

## 输出结构

每次调用产出以下内容：

### 1. 选题矩阵

按 5 个维度各出 3-5 个选题：

| 维度 | 说明 | 示例 |
|------|------|------|
| **热点型** | 借势热点、节日、趋势 | "最近爆火的DeepSeek，普通人怎么用？" |
| **痛点型** | 用户真实困扰、焦虑 | "为什么你学了很多课还是没进步？" |
| **争议型** | 反常识、颠覆认知、站队 | "我劝你别做自由职业" |
| **干货型** | 方法论、技巧、教程 | "3个让你表达力翻倍的训练方法" |
| **人设型** | 个人故事、经历、感悟 | "从月薪3k到3w，我做对了什么" |

### 2. 脚本框架 (推荐 + 备选)

为每个选题推荐 1-2 个脚本结构：

| 框架 | 适合场景 | 结构 |
|------|---------|------|
| **黄金三秒+痛点+方案** | 通用爆款 | 钩子(3s) → 共情痛点 → 解决方案 → 引导 |
| **SCQA** | 知识/观点 | 情景 → 冲突 → 问题 → 答案 |
| **PREP** | 说服型 | 观点 → 理由 → 案例 → 重申观点 |
| **故事钩子** | 人设/叙述 | 悬念开头 → 情节展开 → 转折 → 感悟 |
| **清单体** | 干货/技巧 | "XX个方法" → 逐条展开 → 总结 |

### 3. 差异化角度

针对每个选题给出 2-3 个"爆款切入点"——让选题不撞车的角度。

### 4. 完整大纲（可选）

对选定的 1 个选题展开为 300-500 字的口播脚本大纲，含：
- 开场钩子（具体话术）
- 正文结构（分点/分段）
- 结尾引导（点赞/关注/评论引导）

## 口播类型速查

| 类型 | 核心 | 语速 | 时长建议 |
|------|------|------|---------|
| 知识分享型 | 信息密度 + 易懂 | 中速 | 60-120s |
| 观点输出型 | 立场鲜明 + 逻辑强 | 中快 | 45-90s |
| 故事叙述型 | 情绪起伏 + 真实感 | 慢-中 | 90-180s |
| 产品种草型 | 场景 + 利益点 | 中快 | 30-60s |
| 情绪共鸣型 | 共情 + 金句 | 慢-中 | 30-60s |

## 选题 Checklist

产出选题后，每个选题可自检：
- [ ] 前 3 秒能让观众停下来？(钩子强度)
- [ ] 内容有「信息增量」？(不是常识复读)
- [ ] 观众看完会想转发/评论？(互动钩子)
- [ ] 和你的账号定位一致？(人设一致性)
- [ ] 同赛道有类似内容吗？(差异化≥60%)

## 示例

```
/koubo-brainstorm 职场沟通 内向者
```

输出会包含：
- 选题矩阵（热点/痛点/争议/干货/人设）
- 每个选题推荐脚本框架
- 差异化角度建议
- 最强 1 个选题的完整口播大纲
